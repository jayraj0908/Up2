# Epic 7: Social Mechanics

## Overview
Implement social networking features that enable user connections, event sharing, and community building.

## Description
- Invite friends via shareable link, username, or SMS
- Profile tagging, event attendance history
- Friend-based signal boosts in discovery

## Stories

### Story 7.1: Friend Invitation System
**As a** user,
**I want** to invite friends to events through multiple methods,
**so that** I can easily share events with my social network.

**Acceptance Criteria:**
1. Generate shareable event links for any event
2. Invite friends by searching and selecting usernames
3. Send event invitations via SMS to phone contacts
4. Shareable links work for both registered and unregistered users
5. Invitation tracking shows who was invited and their response status
6. Custom invitation messages can be added
7. Bulk invitation capabilities for multiple friends

### Story 7.2: Friend Network & Following
**As a** user,
**I want** to connect with and follow other users,
**so that** I can build my social network within the app.

**Acceptance Criteria:**
1. Users can search for and find other users by username
2. Send and accept friend/follow requests
3. View friends' event activity and attendance
4. Friends list management (view, organize, remove connections)
5. Friend suggestions based on mutual connections and interests
6. Privacy controls for friend visibility and discoverability
7. Notification system for new friend requests and acceptances

### Story 7.3: Profile Tagging & Event History
**As a** user,
**I want** my profile to show my interests and event history,
**so that** other users can discover shared interests and past experiences.

**Acceptance Criteria:**
1. User profiles display vibe/interest tags
2. Event attendance history is visible on profiles
3. Users can tag themselves in event photos and posts
4. Tagged photos appear on user profiles
5. Privacy controls for event history visibility
6. Profile badges for frequent event attendance
7. Interest-based profile matching and suggestions

### Story 7.4: Friend-Based Discovery Boost
**As a** user,
**I want** to see events that my friends are attending or interested in,
**so that** I can discover events through my social network.

**Acceptance Criteria:**
1. Events attended by friends appear higher in discovery feeds
2. "Friends attending" indicator on event cards
3. See which specific friends are attending events
4. Friend activity notifications for event RSVPs and attendance
5. Social proof indicators in event recommendations
6. Friend-based event filtering in discovery views
7. Social sharing features for events to external platforms
