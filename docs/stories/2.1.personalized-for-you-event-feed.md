# Story 2.1: Personalized "For You" Event Feed

## Status
in review

## Story
**As a** guest user,
**I want** to see a personalized "For You" feed of events,
**so that** I can discover events that match my interests and social connections.

## Acceptance Criteria
1. Feed displays events based on user's mood preferences
2. Feed prioritizes events from user's friend network
3. Feed considers user's location for relevant local events
4. Events are displayed in a scrollable, card-based interface
5. Each event card shows key information (title, date, location, host)
6. User can tap on event cards to view full event details
7. Feed refreshes with new content when user pulls to refresh

### Project Structure Notes
The "For You" feed is the primary discovery mechanism for the app. It should integrate seamlessly with the existing profile and authentication systems while providing a foundation for the upcoming map view (Story 2.2) and trending events view (Story 2.3).

### Feed Implementation Strategy
1. **Initial Load:**
   - Load first page of ranked events
   - Show loading skeleton UI
   - Cache results for offline viewing

2. **Refresh Behavior:**
   - Pull-to-refresh updates ranking
   - Background refresh every 5 minutes
   - Real-time updates for friend activity

3. **Pagination:**
   - Load 20 events per page
   - Infinite scroll with 3-event buffer
   - Maintain scroll position on refresh

4. **Performance Optimization:**
   - Image preloading for next 3 cards
   - View recycling for memory efficiency
   - Background fetch for next page
